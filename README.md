
# 🔄 ShareIt

**ShareIt** — это сервис, где пользователи делятся вещами.  
Это приложение позволяет пользователям, во-первых, рассказывать, какими вещами они готовы поделиться,  
а во-вторых, находить нужную вещь и брать её в аренду на какое-то время.  
Сервис не только позволяет бронировать вещь на определённые даты,  
но и закрывать к ней доступ на время бронирования от других желающих.  
На случай, если нужной вещи нет в данный момент, у пользователей есть возможность оставлять запросы.  
По запросу можно добавлять новые вещи для шеринга.

---

## 🚀 Возможности

- Регистрация и управление пользователями
- Публикация вещей для аренды
- Поиск и фильтрация доступных вещей

- Система отзывов и комментариев
- Подтверждение/отклонение аренды владельцем
- Обработка запросов на вещи

## ⚙️ Архитектура

Проект разделён на два модуля:

### 📦 shareit-server

- Управляет бизнес-логикой: аренда, бронирование, пользователи, предметы
- Содержит REST API
- Использует PostgreSQL для хранения данных

### 🚪 shareit-gateway

- Обрабатывает входящие запросы
- Валидирует входные данные
- Делает проксирование к `shareit-server`

---

## 🧩 Функциональность приложения

**ShareIt** — имеет микросервисную архитектуру. Состоит из 2-х сервисов:

- `gateway` — в этом сервисе выполняется валидация всех запросов от пользователей приложения. Реализовано кэширование для одинаковых запросов.
- `server` — здесь находится вся бизнес-логика приложения и обращение к базе данных.

Приложение соответствует принципам REST API.

---

### 🔄 Основные компоненты

- Контроллеры: `BookingController`, `ItemController`, `RequestController`, `UserController`
- Сервисы: `BookingService`, `ItemService`, `RequestService`, `UserService`
- Репозитории: `BookingRepository`, `ItemRepository`, `RequestRepository`, `UserRepository`

---

### 👥 Возможности для пользователей

- Добавлять новую вещь с кратким описанием
- Искать нужную вещь по ключевым словам в описании или в названии
- Создавать запросы, если нужной вещи нет
- Бронировать вещь на определённые даты (подтверждение владельцем)
- Оставлять отзывы после возврата вещи владельцу

## 🗃️ Схема БД и модели данных

**Модели:**

- `Item` — вещь
- `ItemRequest` — запрос
- `User` — пользователь
- `Booking` — бронирование
- `Comment` — отзыв

📌 Схема БД представлена в модуле `shareit-server` (пакет `model`) и соответствует связям между пользователями, вещами, бронированиями и отзывами.

## 🐳 Запуск с помощью Docker

### Требования

- Docker
- Docker Compose

### Команда запуска

```bash
docker-compose up
```

Контейнеры:

- `gateway`: порт `8080`
- `server`: порт `9090`
- `postgres`: порт `5432`

---

## 📂 Сборка вручную (без Docker)

```bash
# Сборка и установка зависимостей
mvn clean install

# Запуск shareit-server
cd shareit-server
mvn spring-boot:run

# Запуск shareit-gateway
cd ../shareit-gateway
mvn spring-boot:run
```

## 📊 Примеры API

- `POST /items` — добавить вещь
- `GET /items` — список доступных вещей
- `POST /bookings` — создать бронирование
- `PATCH /bookings/{id}` — подтвердить/отклонить бронирование
- `GET /bookings` — список бронирований пользователя
- `POST /items/{id}/comment` — оставить комментарий
